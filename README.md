# TikTok Unrepost https://bkovalev841-source.github.io/tiktok-unrepost/

Кнопка-закладка (bookmarklet), которая удаляет все репосты со своего профиля в TikTok.

Работает только на открытой странице `tiktok.com` — от вашего имени и в вашей сессии. Пароли не нужны, данные никуда не отправляются: запросы идут на сам TikTok из вашего браузера.

## Как пользоваться

1. Откройте страницу `index.html` (локально или на GitHub Pages).
2. Включите панель закладок в Chrome: `Ctrl` + `Shift` + `B`.
3. Перетащите зелёную кнопку «Удалить репосты TikTok» на панель закладок.
4. Зайдите в свой профиль TikTok → вкладка **«Репосты»** → нажмите на закладку.
5. В правом нижнем углу появится панель: «Удалить все репосты», «Стоп», «Перезагрузить страницу».

Если перетаскивать неудобно — создайте закладку вручную и вставьте в поле URL код из `bookmarklet.js` с префиксом `javascript:`.

## Как это устроено

- Список репостов берётся из API TikTok: `/api/repost/item_list/?secUid=…` (резервный источник — сетка на странице профиля).
- Удаление: `POST /tiktok/v1/upvote/delete?item_id=…` с подписью `X-Bogus`, которую считает `window.byted_acrawler.frontierSign` на самой странице TikTok.
- Три параллельных запроса, пауза 0,4–1,1 с между ними.
- Удалённые id сохраняются в `localStorage`, поэтому повторный запуск продолжает с места остановки.

## Ограничения

- Требуется вход в аккаунт в этом же браузере.
- TikTok может ограничить частоту действий: при пачке ошибок нажмите «Стоп» и повторите позже.
- Вёрстка и внутренние API TikTok меняются без предупреждения — тогда скрипт придётся обновить.

## Файлы

- `index.html` — страница установки с кнопкой-закладкой.
- `bookmarklet.js` — исходный код закладки (читаемый, для правок).
