TikTok Unrepost

Удаляет все репосты со своего профиля в TikTok. Код работает только на открытой странице tiktok.com, от вашего имени и в вашей сессии: пароли не нужны, ничего не отправляется на сторонние серверы.

Установка (один раз)

  1. Включите панель закладок в Chrome: Ctrl + Shift + B.
  2. Перетащите мышкой эту кнопку на панель закладок:
    Удалить репосты TikTok
  3. Откройте tiktok.com → свой профиль → вкладка «Репосты» → нажмите на закладку.
  4. Справа снизу появится панель: «Удалить все репосты», «Стоп», «Перезагрузить страницу».
Работает только на странице своего профиля с открытой вкладкой «Репосты». Уже удалённые запоминаются в браузере — повторный запуск продолжит с места остановки.

Если перетащить не получается

  1. Правый клик по панели закладок → «Добавить страницу».
  2. Название: любое, например Удалить репосты.
  3. В поле «URL» вставьте код ниже целиком.

Как это работает

  • Список репостов запрашивается у самого TikTok (/api/repost/item_list/), резервный источник — сетка на странице профиля.
  • Удаление — запрос /tiktok/v1/upvote/delete с подписью X-Bogus, которую считает код TikTok, загруженный на странице.
  • Три запроса параллельно, пауза 0,4–1,1 с. Если TikTok начинает ограничивать действия, нажмите «Стоп» и повторите позже.
